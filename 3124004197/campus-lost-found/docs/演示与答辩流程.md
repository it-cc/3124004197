# 演示与答辩流程

1. 启动 `./start.sh --demo`，明确说明所有带“演示数据”标签的记录是虚构演示线索。
2. 用 demo_lost / demo123456 登录。打开本人“蓝色保温杯”记录，点击“AI 帮我找线索”。说明 AI 比较公开特征、日期和地点，不知道私密特征。
3. 展示候选原因与相关度，强调不是物主概率。进入“图书馆拾得蓝色水杯”，提交演示核验说明。
4. 在另一无痕窗口用 demo_found 登录，进入“我的请求”，检查收到的说明；人工确认特征后“核验通过并确认归还”。
5. 展示归还状态与双方可见联系方式。说明此前公开页面和待核验请求不会显示联系方式。
6. 回到某条记录，连续咨询两次，展示上下文。不要把演示 AI 输出当成真实找回证据。

浏览器测试可能已经确认了演示水杯的归还；如该记录已归还，可新建一对带演示标记的记录，或在新的 DATA_DIR 启动演示数据库。不要修改真实用户记录来重置演示。

答辩重点：真实用户场景；AI 如何把分散的描述变成候选；为什么不自动确认归属；私密核验和联系方式授权；真实调研与上线计划。先说团队，再说选题与需求分析。

# 寻回：校园失物找回助手

用户：丢失／捡到物品的校园成员。主任务：发布线索、找候选、核验归还。不是学校官方身份认证服务。

配色：冷白 #F6F8F4、纸白 #FFFFFF、深绿 #183F2D、灰绿 #657267、纸黄 #C79531、边线 #DCE4D9。中文采用系统黑体，单一字体体系；标题 48／36px、正文 15／14px、辅助标签 12px。

布局：顶栏导航；左侧介绍与明确发布操作，右侧纸质公告板式说明；下面直接进入搜索、筛选与物品网格。不是全屏宣传网站，而是立即可操作的社区工具。

最初 UI/UX 检索返回通用社区紫色营销方案，没有采用其配色和宣传布局；保留高对比、明确标签、响应式网格和可见焦点，使用校园公告板的纸张与森林绿建立具体识别。

物品视觉来自真实上传照片；未上传时采用类别线描，不能假称实物照片。演示数据明确标记，默认无虚构校园信息。无虚构找回率、用户数或客户评价。

交互：原生 dialog 支持 Escape、焦点和移动端滚动；必填字段带真实标签；请求失败显示原因；AI 匹配不能自动确认归属。照片重编码，公开信息不含联系方式或私密核验特征。
